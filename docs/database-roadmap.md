# خريطة قاعدة بيانات سند

## القرار

سنبدأ بقاعدة بيانات محلية داخل برنامج Windows، ثم نضيف المزامنة السحابية عندما نبدأ تطبيق الجوال.

## لماذا لا نبدأ بالسحابة فورًا؟

- نحتاج تثبيت شكل البيانات أولًا: المراكز، الحسابات، الطلاب، التقييمات، الخطة، الجلسات، المنزل، ولغة الإشارة.
- النسخة المحلية تجعل برنامج المركز يعمل حتى لو الإنترنت ضعيف.
- بعد ثبات الجداول نضيف خادم آمن يزامن البيانات مع تطبيق الجوال.

## الجداول الأساسية

- centers: المراكز.
- users: المستخدمون والأدوار.
- students: بيانات الطلاب.
- assessments: التقييمات.
- plans: الخطط التدريبية.
- sessions: الجلسات.
- home_tasks: تمارين المنزل وملاحظات الأهل.
- modules: الوحدات المفعلة لكل مركز.
- sign_library: مكتبة لغة الإشارة، وتدعم صورة أو فيديو لكل إشارة.
- audit_logs: سجل عمليات مالك سند والمستخدمين.

## مسار التنفيذ

1. تحويل البيانات التجريبية الحالية إلى طبقة Models واضحة.
2. إضافة قاعدة بيانات محلية SQLite.
3. حفظ وقراءة الطلاب والتقييمات من القاعدة بدل الذاكرة المؤقتة.
4. إضافة سجل عمليات لكل تعديل مهم.
5. لاحقًا إضافة API ومزامنة للتطبيق الجوال.
